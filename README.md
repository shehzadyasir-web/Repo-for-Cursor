# Snake

A 2D snake game. Eat the fruit, grow longer, and don't meet a wall or yourself.

## Play

```bash
npm install
npm run dev
```

Open the URL Vite prints.

- Arrows or WASD turn the snake. Two turns can be queued, so a quick corner still lands.
- Space or Escape pauses. M toggles sound.
- On a touch screen, swipe the board or use the pad. Tap the board to pause.
- Solid edges end the run. Wrap edges send you in on the far side.
- The snake speeds up as the score climbs. Filling every cell wins.

Best score, sound, and the edge rule stay in this browser.
